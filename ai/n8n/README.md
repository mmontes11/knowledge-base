# n8n

[n8n](https://n8n.io) is a fair-code ("sustainable use" licensed) workflow automation platform with native AI capabilities: workflows are built on a visual canvas from 400+ built-in integration nodes, triggers (webhook, schedule, chat, MCP server) and code, and can be driven manually, by schedule, by webhook, or by agents. On top of that, n8n exposes a REST API (workflows, executions, credentials, users, projects, …), a command-line client, built-in data tables for structured storage, and enterprise capabilities such as RBAC, audit log, SSO (SAML/OIDC/LDAP), and source control. It self-hosts with Docker or Helm or runs on n8n Cloud.
