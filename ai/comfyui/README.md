# comfyui

[ComfyUI](https://www.comfy.org/) is the most powerful and modular diffusion-model GUI, API, and backend, organized as a [graph/nodes interface](https://github.com/comfyanonymous/ComfyUI): a visual node graph for building and reusing image, video, audio, 3D, and text generation workflows without code, running fully offline on local hardware and integrating into production pipelines through its HTTP API and WebSocket event channel.

- Upstream repository: https://github.com/comfyanonymous/ComfyUI (repository is now maintained under the [Comfy-Org](https://github.com/Comfy-Org/ComfyUI) organization; the `comfyanonymous/ComfyUI` URL redirects to it)
- Documentation: [comfy.org](https://www.comfy.org/) and [docs.comfy.org](https://docs.comfy.org/); API specification: [openapi.yaml](https://github.com/Comfy-Org/ComfyUI/blob/master/openapi.yaml) at the repository root
- License: [GPL-3.0](https://github.com/Comfy-Org/ComfyUI/blob/master/LICENSE)
- Default branch: `master`; release cycle is roughly weekly (targeting Monday), with a new stable major version released roughly every 2 weeks — see [Release Process](https://github.com/comfyanonymous/ComfyUI#release-process) in the upstream README
