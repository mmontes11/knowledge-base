# traefik — releases

Latest 10 official releases, newest first. Traefik maintains **three supported version lines** (e.g. `v3.7.x`, `v3.6.x`, `v2.11.x`); patches for CVEs and Kubernetes-provider fixes land on all of them, so watch the whole set, not just the newest line. Check ⚠️ entries before upgrading. Version-line migration guides: [v3.7](https://doc.traefik.io/traefik/v3.7/migrate/v3/), [v3.6](https://doc.traefik.io/traefik/v3.6/migrate/v3/), [v2.11](https://doc.traefik.io/traefik/v2.11/migration/v2/).

## v3.7.12 — 2026-08-26

[Release page](https://github.com/traefik/traefik/releases/tag/v3.7.12)

- Security fixes: [GHSA-cjr6-pf59-jq29](https://github.com/advisories/GHSA-cjr6-pf59-jq29), [GHSA-7ghq-v6jf-g56c](https://github.com/advisories/GHSA-7ghq-v6jf-g56c), [GHSA-rf44-j88r-hh8c](https://github.com/advisories/GHSA-rf44-j88r-hh8c).
- ⚠️ **New `aliasHeadersStrategy` entrypoint option deprecates `underscoreHeadersStrategy`** (introduced in v3.6.20): it handles *all* header-name aliasing characters, not just underscores. Default `keep` preserves existing behavior, but setting `underscoreHeadersStrategy` now logs a deprecation warning, configuring both with different values invalidates the config, and every entrypoint left without the option logs a startup warning. [v3.7 migration guide](https://doc.traefik.io/traefik/v3.7/migrate/v3/#v3712)
- ⚠️ **Negative weights in TCP/UDP weighted services are now rejected**: such a service is reported as `disabled` in the API and its routers are not created (previously the negative weight made the load-balancer loop endlessly, burning a CPU core and blocking the service until restart). Replace negative weights with a positive value or `0`. [v3.7 migration guide](https://doc.traefik.io/traefik/v3.7/migrate/v3/#v3712)
- Bug fixes: HTTP/3 timeouts ([#13717](https://github.com/traefik/traefik/pull/13717)), aliasing header names ([#13720](https://github.com/traefik/traefik/pull/13720)), Kubernetes TLS option name collision ([#13721](https://github.com/traefik/traefik/pull/13721)), TCP/UDP weighted-service weight validation ([#13749](https://github.com/traefik/traefik/pull/13749)), fasthttp v1.73.0 ([#13769](https://github.com/traefik/traefik/pull/13769)).

## v3.7.11 — 2026-08-19

[Release page](https://github.com/traefik/traefik/releases/tag/v3.7.11)

- Security fixes: [GHSA-5w68-77r2-r64c](https://github.com/advisories/GHSA-5w68-77r2-r64c), [GHSA-g55h-rg46-x9c5](https://github.com/advisories/GHSA-g55h-rg46-x9c5), [GHSA-j994-9gqj-9hwq](https://github.com/advisories/GHSA-j994-9gqj-9hwq), [GHSA-m6wx-622r-48r9](https://github.com/advisories/GHSA-m6wx-622r-48r9).
- ⚠️ **New `safeNaming` provider option (opt-in)**: collision-safe names for the routers, middlewares and services generated by the Kubernetes CRD provider, derived from object identity instead of flattened/normalized names. Disabled by default (existing names unchanged); when enabled, the user-visible names in the dashboard, access logs, and metrics labels change. [v3.7 migration guide](https://doc.traefik.io/traefik/v3.7/migrate/v3/#v3711)
- ⚠️ **New `core.strictTLSOptions` install option (opt-in, enabling recommended)**: disables the fallback to `default` TLS options when several routers on the same entrypoint serve one hostname with conflicting TLS options (which could drop mutual-TLS enforcement, see GHSA-g55h-rg46-x9c5). Fails closed: conflicting routers are marked in error and not built. [v3.7 migration guide](https://doc.traefik.io/traefik/v3.7/migrate/v3/#v3711)
- ⚠️ **New `defaultTLSResourcesNamespace` provider option**: the `default` `TLSOption`/`TLSStore` are cluster-wide regardless of namespace — this reserves them to an operator-controlled namespace; a `default` defined outside it is ignored. Addresses [GHSA-m6wx-622r-48r9](https://github.com/advisories/GHSA-m6wx-622r-48r9). [v3.7 migration guide](https://doc.traefik.io/traefik/v3.7/migrate/v3/#v3711)
- Bug fixes: Gateway API `URLRewrite`/`RequestRedirect` encoded-path handling ([#13641](https://github.com/traefik/traefik/pull/13641)), Gateway API router rules ([#13645](https://github.com/traefik/traefik/pull/13645)), generated-name collision prevention ([#13656](https://github.com/traefik/traefik/pull/13656), [#13677](https://github.com/traefik/traefik/pull/13677), [#13689](https://github.com/traefik/traefik/pull/13689)), scope of generated Service names ([#13668](https://github.com/traefik/traefik/pull/13668)), restrict default TLS namespace ([#13665](https://github.com/traefik/traefik/pull/13665)), TLS fallback-disable option ([#13639](https://github.com/traefik/traefik/pull/13639)).

## v2.11.55 — 2026-08-18

[Release page](https://github.com/traefik/traefik/releases/tag/v2.11.55)

- Security fixes: [GHSA-5w68-77r2-r64c](https://github.com/advisories/GHSA-5w68-77r2-r64c), [GHSA-g55h-rg46-x9c5](https://github.com/advisories/GHSA-g55h-rg46-x9c5).
- ⚠️ **Kubernetes Gateway API provider: generated router and service names change** — route values are now double-quoted in built rules instead of backquoted (a value can no longer alter the rule it is embedded in), and the generated names embed a hash of the rule, so they change. Names appear in dashboards, access logs (`RouterName`/`ServiceName`), and metrics labels: matching queries must be updated. [v2.11 migration guide](https://doc.traefik.io/traefik/v2.11/migration/v2/#v21155)
- ⚠️ **New `core.strictTLSOptions` static option (opt-in, enabling recommended)**: fails closed on conflicting TLS options instead of falling back to `default` (see GHSA-g55h-rg46-x9c5). [v2.11 migration guide](https://doc.traefik.io/traefik/v2.11/migration/v2/#v21155)
- ⚠️ **New `safeNaming` provider option (opt-in)** and **`defaultTLSResourcesNamespace` provider option**: same Kubernetes CRD changes as in v3.7.11 (collision-safe generated names; cluster-wide `default` `TLSOption`/`TLSStore` reserved to one namespace). Both preserve existing behavior when unset. [v2.11 migration guide](https://doc.traefik.io/traefik/v2.11/migration/v2/#v21155)
- Bug fixes: Kubernetes CRD name-collision fixes ([#13656](https://github.com/traefik/traefik/pull/13656), [#13665](https://github.com/traefik/traefik/pull/13665), [#13668](https://github.com/traefik/traefik/pull/13668), [#13689](https://github.com/traefik/traefik/pull/13689)), Gateway API router rules ([#13645](https://github.com/traefik/traefik/pull/13645)), TLS fallback-disable option ([#13639](https://github.com/traefik/traefik/pull/13639)), go-http-auth and `golang.org/x` dependency bumps ([#13636](https://github.com/traefik/traefik/pull/13636), [#13699](https://github.com/traefik/traefik/pull/13699)).

## v3.7.10 — 2026-07-31

[Release page](https://github.com/traefik/traefik/releases/tag/v3.7.10)

- Security fixes: [GHSA-fgjj-px3w-67xx](https://github.com/advisories/GHSA-fgjj-px3w-67xx), [GHSA-62fc-8686-hfmq](https://github.com/advisories/GHSA-62fc-8686-hfmq), [GHSA-6765-c87h-8mrf](https://github.com/advisories/GHSA-6765-c87h-8mrf).
- ⚠️ **Kubernetes Gateway API provider: generated router, middleware, and service names change** — the hash suffix is now derived from all route/Gateway/listener identifying fields (not just the rule), and generated *service* names are prefixed with the route rule. Names appear in dashboards, access logs (`RouterName`/`ServiceName`), and metrics labels: matching queries must be updated. [v3.7 migration guide](https://doc.traefik.io/traefik/v3.7/migrate/v3/#v3710)
- ⚠️ **Gateway API spec v1.6.1 support**: `TCPRoute`/`TLSRoute` are not served by the standard-channel v1.6.1 CRDs — install the experimental-channel CRDs or the Gateway API provider will not start. [v3.7 migration guide](https://doc.traefik.io/traefik/v3.7/migrate/v3/#v3710)
- Bug fixes: authentication singleflight key-collision fix ([#13572](https://github.com/traefik/traefik/pull/13572)), Gateway API router name collision ([#13580](https://github.com/traefik/traefik/pull/13580)), lego v5.3.1 ([#13547](https://github.com/traefik/traefik/pull/13547)), dd-trace-go 2.8.1.
