# HAMi

HAMi (Heterogeneous AI Model Instance) is a Kubernetes GPU virtualization and heterogeneous accelerator scheduling platform for AI infrastructure. It provides fractional GPU allocation (vGPU), MIG support, multi-vendor device management, and advanced scheduling policies. CNCF Incubating project.
